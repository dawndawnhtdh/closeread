# CloseRead 中文操作手册

## 1. CloseRead 能解决什么问题

技术文档的价值不仅在于“知道大意”，还在于理解术语在当前语境中的含义、条件和逻辑关系。整页网页翻译经常会统一替换术语、弱化限定条件，或者让读者完全离开英文原文。

CloseRead 的目标是让你始终围绕英文原句学习：先读原文，再看整句翻译，然后理解句式，最后把需要记忆的词连同原句加入生词本。

## 2. 使用前准备

### 2.1 安装 Node.js

建议安装 Node.js 18 或更高版本。安装完成后，在终端运行：

```bash
node --version
npm --version
```

两个命令都能显示版本号，即表示环境可用。

### 2.2 创建 DeepSeek API Key

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys)。
2. 登录并创建一个新的 API Key。
3. 妥善保存以 `sk-` 开头的完整 Key。
4. 检查账户是否有可用余额。

不要在聊天、截图、公开 Issue 或 Git 提交中公开 API Key。

## 3. 启动 CloseRead

### 3.1 使用 macOS 桌面版

如果已经安装了 CloseRead 桌面应用，可以打开“启动台”，搜索 `CloseRead`，然后点击绿色书本图标启动。也可以在 Finder 的“应用程序”文件夹中双击 `CloseRead.app`。

桌面版不需要保持终端或 Vite 服务运行。首次打开时仍需在右上角设置中填写 DeepSeek API Key。

如果系统提示应用来自未识别开发者，可以在 Finder 中按住 `Control` 点击 CloseRead，选择“打开”，再在确认窗口中点击“打开”。个人本地构建使用临时签名；正式对外分发需要 Apple Developer ID 签名和公证。

### 3.2 使用源码运行

首次运行：

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/closeread-english.git
cd closeread-english
npm install
npm run dev
```

终端显示以下地址后，说明启动成功：

```text
http://127.0.0.1:5173/
```

运行期间不要关闭这个终端窗口。结束使用时，可以在终端按 `Control + C` 停止服务。

## 4. 连接 DeepSeek

1. 打开 CloseRead 页面。
2. 点击右上角设置图标。
3. 在“DeepSeek API Key”中只粘贴完整 Key。
4. 模型保持 `deepseek-chat`。
5. 点击“保存本次设置”。

Key 只在当前页面中保留。刷新或关闭页面后，需要重新填写。

## 5. 完成一次精读

### 5.1 粘贴原文

将英文技术文档复制到左侧输入框。第一次建议使用 2 到 5 句话，熟悉流程后再增加内容。单次输入上限是 8,000 个字符。

### 5.2 选择讲解深度

1. “简明”适合快速理解，只解释最重要的语法点。
2. “详细”适合系统学习，会完整说明主干、从句和固定搭配。
3. “技术英语”会加强 API、AI、软件工程等术语和表达的解释。

### 5.3 开始解析

点击“开始精读”。解析完成后，页面会显示文档主题、阅读重点和逐句结果。

## 6. 阅读逐句结果

推荐按照以下顺序阅读：

1. 先独立阅读英文原句，不立即看翻译。
2. 查看“整句翻译”，确认自己遗漏的信息。
3. 阅读“逐词对照”，理解每个词在当前句子里的具体含义。
4. 查看“句式骨架”，找到主句和从句之间的关系。
5. 阅读语法说明，理解被动语态、非谓语、关系从句和固定搭配。
6. 使用左右箭头切换上一句或下一句。

点击朗读按钮可以听整句或单词的英文发音。

## 7. 使用逐词对照与注释

每个单词卡片会显示：

```text
英文原词
当前语境中文释义
词性 · 音标
```

点击卡片后，右侧会进一步显示：

1. 这个词在当前句子中的释义。
2. 相关搭配、词形或句中作用。
3. 单词出现的英文原句。
4. 原句的中文翻译。

CloseRead 重点解释当前语境，不会把字典里的所有释义一次性堆给你。

## 8. 管理生词本

在单词详情区域点击“加入生词本”。生词本会保存单词、语境释义、英文原句和整句翻译。

进入顶部“生词本”后，可以：

1. 搜索单词、释义或原句。
2. 将单词标记为“已掌握”。
3. 删除不再需要的词。
4. 导出 CSV，用于 Excel、Notion 或其他复习工具。

同一个单词在不同句子里可能有不同含义，因此 CloseRead 会按“单词 + 原句”保存记录。

## 9. 更有效的使用方法

1. 每次精读 3 到 8 句，比一次粘贴整篇文档更容易吸收。
2. 第一次先遮住翻译，尝试自己找主干。
3. 只收藏真正影响理解或以后会复用的词。
4. 复习生词时先读原句，再回忆中文含义。
5. 对 API 参数、错误提示和限定条件，优先保留英文原词。
6. AI 可能犯错；涉及安全、合规和生产操作时，应回到官方原文确认。

## 10. 故障排查

### `DeepSeek API Key 格式不正确`

只粘贴 `sk-...`，不要包含中文说明、引号或空格。

### `Authentication Fails`

Key 无效、已删除或复制不完整。请在 DeepSeek 控制台重新创建。

### `Insufficient Balance`

DeepSeek 账户余额不足，需要充值后再试。

### `fetch failed`

本机无法访问 DeepSeek。检查网络、防火墙和代理设置，然后重新启动 `npm run dev`。

### 页面一直显示本地预览

刷新会清除 Key。重新打开设置填写 Key，然后再次点击“开始精读”。

### 翻译或逐词释义不完整

将文档拆成更短的段落，选择“详细”或“技术英语”后重新解析。过长文本可能导致模型输出被截断。

## 11. 隐私边界

CloseRead 的生词本保存在浏览器本地，但 AI 解析必须将粘贴的英文内容发送给 DeepSeek。请遵守所在组织的数据安全要求，不要处理密钥、个人隐私、客户机密、未公开代码或其他受限制材料。
